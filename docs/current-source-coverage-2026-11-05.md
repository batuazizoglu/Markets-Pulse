# Current source coverage — 5 November 2026

The daily brief counted two shared catalogues and one archived home source as failed checks. The 08:12 UTC production scan had 48 healthy independent sources out of 53, not eight failures. Coverage now counts each canonical catalogue once, excludes retired/archived sources, and still reports stale, missing and failed independent checks. An orphan shared entry cannot establish successful coverage.

Advertising coverage previously came from the most recently published AI analysis feed. Empty scans and unchanged creatives need not publish another analysis, leaving reports stale. Both the report and dashboard now derive coverage directly from the latest cloud jobs and provider runs. Successful nonempty provider runs now have job status `ok`. The historical report cutoff is retained; observations use the source start time, never a delayed image import or AI timestamp. Full provider coverage still requires its expected ad count, completeness confirmation, exhausted dataset and no limit, rejection or missing-media failures.

A lost paid-start response can now be reconciled with read-only Apify requests. The search is bounded to the original request window and at most three candidates. Exactly one candidate must have the same page, country, active filter and capture input, with no result/date limit. Multiple, missing, truncated or invalid matches keep the original creation fence and spend reservation. Reconciliation never creates or resurrects a paid run. It is attempted only when the capture worker is idle, with daily backoff and longer supplier Retry-After respected. An accepted match resumes its existing dataset with its original observation timestamp; another local job cannot claim the same run.

External limitations remain observable. The 5 November scan reported Airmax connection refusal, Cyprus Sky DNS absence, Flytom/Flynet an incomplete TLS certificate chain, Longnet a certificate hostname mismatch, and Gold Surf direct/proxy connection timeouts. These are not treated as successful checks. Flynet now reads the same official page through Chromium's normal certificate verifier, without scripts, cache, third-party requests or ignored certificate errors. Longnet uses the official apex address indexed by its site; the prior www address remains an alias. These transport changes require production scan verification. The current official directory still lists Airmax and Cyprus Sky at those hostnames. Public retrieval could read Gold Surf's site from another network, but this does not prove availability from production. TLS verification and access-denial behavior are unchanged.

The morning advertising runs downloaded all media they found, but five nonempty runs lacked an expected source count. A fully downloaded dataset is not substituted for that missing declaration. No budgets are increased and no email is manually sent by this maintenance.
